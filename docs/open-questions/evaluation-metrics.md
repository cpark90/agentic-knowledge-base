# 어느 지표를 쓰고 어느 것이 게이트인가

## 질문
체계가 잘 돌아가는지를 무엇으로 재는가? 후보 12개가 이미 열거되어 있지만 "초기 집합이며
확정 목록이 아니다"라고 못 박혀 있다. 어느 것을 쓰고, 어느 것이 **게이트**(임계 위반 =
실패)이며 어느 것이 **관측**(추세만)인가?

## 이미 정해진 것
후보 12개 — 인지능력(입력 정보 누락률) · 추적 커버리지 · 가정 건전성 (d-0145) / 라벨
대표성 · 고아율 · 크기 분포 · `draft` 체류 시간 (d-0080) / 링크 밀도 · `suspect` 비율 ·
평균 재판정 지연 · 복원 비율 · 확정 정밀도 (d-0112). 지표 각각이 메커니즘 하나에 대응하므로
어느 지표가 나빠졌는지가 곧 어느 메커니즘을 손볼지를 가리킨다.

## 현재 상태
지금 계산 가능한 것은 고아율·크기 분포·항목 수뿐이고, 나머지는 링크·실행 기록·시나리오가
없어 분모가 없다. **자동 측정이 하나도 없다** — 손으로 센다. 그래서 문서의 수치가 낡는
사고가 실제로 있었다.

## 답이 가르는 것
`metrics` 도구가 무엇을 계산하고, 그중 무엇이 `bazel test`를 실패시키는가. 게이트로 만들면
지표가 규율이 되고, 관측으로 두면 추세만 본다.

## 선택지
- **A. 단계 연동** — 12개 전부 측정(관측)하되 게이트 임계는 methodology 각 단계의 완료
  판정만. 예: 저작 단계 = 고아율·크기 분포, 연결 단계 = 링크 밀도·복원 비율.
- **B. 전부 관측, 게이트는 고아율만** — 최소 개입.
- **C. 라벨 대표성을 핵심으로** — 유일하게 "지식의 질"을 재는 지표. 에이전트 실험 비용이 크다.
