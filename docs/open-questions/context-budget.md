# 컨텍스트 예산의 실측 — 42줄이 실제로 성립하는가

## 질문
체계 전체가 "에이전트가 한 번에 파악하는 맥락 ≈ 200줄"과 "그중 지식 본문은 잔여"라는 전제
위에 있다. 이 수치는 **실측된 적이 없다.** 하네스 지시·situation·툴 출력·대화 이력이 실제로
얼마를 차지하는지 재지 않으면 42줄이 맞는지, 30줄이어야 하는지, 상한 자체가 무의미한지 알 수
없다.

## 이미 정해진 것
- 예산 5항목(하네스 지시 · situation · 툴 출력 · 대화 이력 · 지식 본문)과 각각의 통제 수단.
  지식 본문만 잔여다 (d-0041). 실측 필요가 대안절에 명시되어 있다.
- 읽기 응답은 라벨 목록이 기본 (d-0082) — 툴 출력 통제 수단.
- dispatch 재진입 요약은 스코프로 거른 situation (d-0126) — 대화 이력 통제 수단.

## 현재 상태
- **하네스 지시**: 세션 시작 시 읽는 문서(`CLAUDE.md` + `AGENTS.md` + `STYLEGUIDE.md` +
  역할 정의)가 재편 전 **408줄**이었다. 200줄 예산의 두 배다. 재편 후 다시 재야 한다.
- **situation**: 라벨 목록이 항목 수만큼(153줄). 스코프로 걸러도 `decision` 전체를 읽는
  역할은 그대로 본다.
- **툴 출력**: 파일 하나 읽기가 100~300줄.
- 항목 본문 실측: 최빈 15줄 · 최대 22줄 · 42줄 근처 0 (n=153) — 상한에 눌린 흔적은 없다.

## 답이 가르는 것
42줄 상한의 근거가 유지되는가, 그리고 "200줄"이 컨텍스트 창 크기와 다른 것(한 판단에
조망하는 단위)으로 재정의되어야 하는가.

## 선택지
- **A. 하네스 지시부터 압축하고 항목별로 측정** — 명백한 위반을 먼저 고치고 수치를 잰다.
- **B. 전제를 재정의** — "200줄"을 조망 단위로 정의하고 컨텍스트 창과 분리한다.
- **C. 유지** — 실측 없이 42줄을 그대로 둔다. 근거가 경험칙에 머문다.
