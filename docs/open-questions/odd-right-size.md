# ODD의 적정 크기를 무엇으로 판정하는가

## 질문
ODD가 작으면 파생물(스코프·가정·시나리오)이 참조할 속성이 부족해 지식을 만들 수 없고, 크면
커버리지 분모가 커져 같은 시나리오 집합의 커버리지가 떨어지고 대조·유지 비용이 는다.
**몇 개의 조건이 적정한가**, 그리고 적정성을 무엇으로 판정하는가?

## 이미 정해진 것
- 필수 절 6개와 조건 3분류, 값·판정 방법·등급 (d-0059).
- 판정 등급 D는 넣지 않는다 — 크기의 **하한 필터**는 있다 (d-0064).
- 변경은 확장·축소·정밀화 셋이고 온톨로지가 선행한다 (d-0062) — 줄이는 절차는 있다.
- ODD가 커지면 커버리지가 떨어진다 — 크기의 **비용**은 정의되어 있다 (d-0135).
- 명시 제외 절이 "검토했으나 밖에 둔 것"을 담는다 — 크기를 키우지 않고 검토 흔적을 남긴다.

## 현재 상태
조건 7개(등급 A 5 · B 2), 명시 제외 3건. 그런데 **조건 7개 중 가정이 실제로 참조하는 것은
1개**뿐이다(가정 자체가 1개라서). 스코프는 4개 조건을 참조한다. 참조되지 않는 조건이 과대의
신호일 수 있고, 가정을 못 적는 항목이 과소의 신호일 수 있는데 후자는 지금 확인할 수 없다.

## 답이 가르는 것
ODD를 언제 늘리고 언제 줄이는가. 판정 기준이 없으면 ODD는 한 방향으로만 자란다.

## 선택지
- **A. 수치 상한 없이 두 지표로 조정** — **참조율**(조건 중 가정·스코프가 실제 참조하는 비율,
  낮으면 과대)과 **기각률**("ODD에 없는 조건" 게이트 거부 횟수, 높으면 과소). 변경 절차를
  이 둘에 연동한다.
- **B. 조건 수 상한 7±2** — 단순하나 근거가 약하다.
- **C. 프로파일 입력** — 코어는 정하지 않는다.
