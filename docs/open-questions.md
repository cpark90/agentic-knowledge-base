# 미해결 질문 — 자리 안내

미결 목록은 이 문서에 없다. 목록은 생성 뷰 `bazel build //kg:open`(`bazel-bin/kg/open.md`)이고 원본은 둘이다.

- **설계 공간** `space/*-space.md` — 상세 다섯 절(질문 / 이미 정해진 것 / 현재 상태 / 답이 가르는 것 / 선택지)을
  가진 미결 하나가 공간 하나다(유저 결정 Q54-a). 뷰는 공간마다 status · 변수 · 후보 state 별 수 · 그 공간을
  가리키는 슬롯을 낸다.
- **선택 슬롯** `미확정:` — 답이 오면 가장 먼저 바뀔 청크 본문의 한 줄이다
  ([`p4-three-empty-values`](../kb/dev/decision/p4-three-empty-values/conclusion.md)). 상세가 있으면 슬롯이 공간
  IRI를 가리킨다.

손으로 관리하던 색인과 `open-questions/`의 상세 파일은 지시 0095로 걷었다. 예외는 하나다.

- 이 문서는 규범 문서 [`rules.md`](rules.md)의 결정 복합체 절이 링크하는 동안 남는다. 그 절이 "등록된 미해결"이라
  부르는 긴장(결정 복합체의 수준 혼합과 동질성 규칙)은 닫혔다. 결정 `p4-composition-rules`의 규약이 결정 복합체를
  동질성의 level 예외로 정했다(2026-09-13). 그 절의 링크가 바뀌면 이 문서를 지운다.
