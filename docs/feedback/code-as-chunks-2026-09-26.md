# 코드를 청크로 올릴 것인가 — `artifact` plane 과 검증 대응물 (2026-09-26 중계)

원본: [`agents/orchestrator-verdict-and-verifier-2026-09-22.md`](agents/orchestrator-verdict-and-verifier-2026-09-22.md) §2

## 질문

vnv 가 검증기 셋에 `verifies` 를 **하나도 달지 못했다.** `verifies` 는 같은 수준의 개발 KB 항목을 대상으로 해야 하는데
개발 KB 에 `executable` 수준 항목이 0이고 `artifact` plane 도 0이다. **사다리 대응이 개발 쪽에서 비어 있다.**

어려운 이유는 이것이 검사 하나의 문제가 아니라 **저장소의 작업 방식을 바꾸는 판단**이라는 데 있다. 이 저장소의 코드는
`tools/*.py` 이고 청크로 올라와 있지 않다. 올리면 `artifact` plane 이 서고 검증기가 대상을 갖지만, 코드를 42줄 청크로
저작·유지하는 방식으로 옮겨간다.

## 이미 정해진 것

- 결정 `p7-dev-plane-substance` — `artifact` plane 의 실체는 **함수 하나가 청크 하나**이고 42줄을 넘는 함수는 분할한다.
- `verifies` 는 같은 수준의 개발 KB 청크를 대상으로 한다(`defs/kb.bzl`). 2026-09-23 유저 승인으로 도착점은 개발 KB 청크다.
- 로드맵 6단계의 tangle — 복합체의 `artifact` 부분을 `co:index` 순으로 이어 붙여 코드 파일을 만든다. **미착수다.**
- 요구 `r-009` — 모든 산출물은 요구로 거슬러 오른다.

## 현재 상태 (실측 2026-09-26, hci 확인)

- `tools/` 는 파이썬 **34 파일 · 9,246줄**이다. 함수 하나가 청크 하나면 청크 수백 개가 생긴다.
- 개발 KB 의 `artifact` plane **0** · `executable` 수준 **0**. V&V 쪽 `artifact` 3(검증기)만 있고 그 셋은 `verifies` 대상이 없어 본문에 "검증 대응물 — 없음"을 적었다.
- 전방 추적(CQ19) **24/69 = 34.8%** 다. `executable` 까지 닿은 요구가 적은 이유가 이 공백이다.
- tangle 도구가 없으므로 지금 코드를 청크로 올리면 **청크가 원본이고 파일이 생성물**이 되는데 그 생성 경로가 없다.

## 답이 가르는 것

- **올리면** `artifact` plane 과 `executable` 수준이 서고 검증기가 대상을 갖는다. 전방 추적이 오르고 `r-009` 가 코드까지 닿는다. 대신 tangle 이 없으면 **청크와 파일의 이중 관리**가 생기고, 있으면 저작 방식이 바뀐다(코드를 청크로 쓰고 파일을 생성한다).
- **올리지 않으면** 검증기는 계속 대상 없이 남고 전방 추적의 상한이 고정된다. `p7-dev-plane-substance` 는 규칙만 있고 실행이 없는 상태로 남는다.
- **일부만 올리면**(예: 게이트 도구의 핵심 함수) 사다리가 일부 구간에서 닫힌다. 어디까지가 "지식으로 관리할 코드"인지의 경계를 정해야 한다.

## 선택지

1. **일부만 올린다 — 게이트 검사 함수부터** (권고). `kb_lib` 의 검사 함수처럼 **규칙을 직접 구현한 함수**만 청크로 올린다. 그 함수들은 이미 결정·요구와 1:1 대응이 있고 검증기의 대상이 된다. 비용: 청크 수십 개 + tangle 첫 형태. 나머지 코드는 파일로 남긴다.
2. **전부 올린다.** `tools/` 34 파일을 청크로 옮기고 tangle 로 파일을 생성한다. 비용: 청크 수백 개 + tangle 완성 + 저작 방식 전환. 전방 추적이 100% 를 향한다.
3. **올리지 않고 검증기의 대상 규칙을 넓힌다.** `verifies` 가 `executable` 없는 경우 `concrete` 결정을 대상으로 허용한다. 비용: 검사 약화 승인. 사다리 대응의 뜻이 느슨해진다.
4. **지금은 두고 tangle 뒤에 판단한다.** 검증기 셋은 "검증 대응물 없음"으로 남긴다. 비용: 전방 추적 상한 고정.
