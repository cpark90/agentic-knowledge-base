# 용어 정규화 — 지어낸 말을 표준 용어로

## 질문

유저 지적(2026-09-10): "현재 전체 문서 및 에이전트가 사용하는 단어가 일반적이지 않은 단어들이야.
전체 단어 확인하고 정규화 진행해줘." 0.0절·STYLEGUIDE의 원칙("지어낸 용어 금지, 표준어를 쓴다")이
어휘(온톨로지 영문 라벨)에는 적용됐지만 **한글 산문과 한글 라벨**에는 적용되지 않았다 — 은유(가로대·
사다리·상승·하강·장부·센서·위생), 자체 조어(거주표·상주표·정제 높이·재판정 경계·봉사·투영), 오역
(경쟁 질문, 평가)이 섞여 있다. 어려운 이유: 대체는 문서 20여 개·결정 546 파일·온톨로지 한글 라벨·
노트 3,470줄에 걸치고, 한 낱말이 둘로 갈라진 곳(거주표/상주표)과 한 낱말이 두 뜻인 곳(평가 =
validation과 evaluation)이 있어 기계 치환만으로는 안 된다. 대응표가 곧 결정이라 먼저 확인을 받는다.

## 이미 정해진 것

- 지어낸 용어 금지, 표준어 우선, 고유 관계는 표준 관계의 하위 속성 (0.0절, `p0-agt-namespace`, STYLEGUIDE §0)
- 지식의 종류는 고유 용어로, "X 청크"라 하지 않는다 (유저 결정 2026-09-04) — **청크**는 유지
- 산문은 한글, 식별자·영문 라벨은 영어 (AGENTS.md 언어 정책) — 영문 식별자(`refines`·`serves`·`Composite`·`plane`)는 바꾸지 않는다
- 온톨로지 한글 라벨은 게이트 대상(labels 검사) — 라벨을 바꾸면 그래프가 바뀐다

## 답이 가르는 것

- 표대로 가면 온톨로지 한글 라벨 6개(구성체·봉사·투영·거주표·논평·장부 계열)와 결정 라벨 수십 개가 바뀐다 — 그래프의 `rdfs:label@ko`가 바뀌므로 게이트를 다시 돌리고 `index.md`·`metrics`가 재생성된다. IRI·영문 라벨은 그대로라 링크는 깨지지 않는다.
- "평가→확인"은 문맥 판별이 필요해(validation vs evaluation) 기계 치환이 아니라 파일별 검토다 — 결정 47건.
- 노트를 바꾸지 않으면 재도출된 결정과 원문의 용어가 갈린다. 노트를 바꾸면 `(노트 N.N절)` 인용은 그대로 유효하다(절 번호 불변).
- 유지로 둔 것(판정·프로파일·plane·level·이탈·되먹임)을 바꾸고 싶으면 이 표에서 지정한다.

## 선택지

1. **표대로 대체 22건, 유지 10건** — 순서: 용어집 `docs/glossary.md`(현재→표준, 출처) 확정 → STYLEGUIDE §0에 "용어집 밖 낱말 금지" → 기계 치환(문서·결정·에이전트 정의) → 문맥 항목(평가) 수작업 → 온톨로지 라벨 → 노트·구조도 → 게이트·링크·재생성. 비용: 커밋 하나에 파일 600여 개. (권고)
2. **산문만 대체, 온톨로지 한글 라벨·노트는 유지** — 그래프와 유저 문서를 건드리지 않는다. 비용: 산문과 라벨·원문의 용어가 갈려 검색이 둘로 나뉜다.
3. **용어집만 만들고 대체는 새 저작부터** — 기존 문서는 그대로. 비용: 정규화가 실제로는 일어나지 않는다.
