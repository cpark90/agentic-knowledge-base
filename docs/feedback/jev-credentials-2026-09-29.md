# 판정 서비스의 자격과 비용 (2026-09-29)

원본: [`agents/orchestrator-accept-jev-judge-binding-2026-09-26.md`](agents/orchestrator-accept-jev-judge-binding-2026-09-26.md)

## 질문

판정자 도구 `judge` 가 섰으나 **자격이 없어 측정을 시작할 수 없다.** 엔드포인트·키·모델 식별자를 줄 것인가, 아니면
오프라인 고정물로만 돌릴 것인가.

어려운 이유는 자격이 저장소 밖의 것이라는 데 있다. 도구는 있고 규약도 있으나 **실측이 없으면 3지표(정확도·판별력·
캘리브레이션)를 영원히 못 잰다** — 2026-09-11 라벨 실험이 캘리브레이션에서 "판정 불가"로 끝난 상태가 그대로다.

## 이미 정해진 것

- 판정자는 **게이트 밖 도구**다(유저 승인 2026-09-26). 게이트는 판정 로그의 존재와 형식만 본다.
- 결정 `p8-judge-question-form` 개정판 — 확신도는 집단 수준 캘리브레이션이고 구간당 표본은 20이다.
- 자격이 없으면 `--fixture` 오프라인 모드로만 돈다(도구가 그렇게 섰다).
- 외부 의존은 ODD 조건으로 올린다(같은 승인).

## 현재 상태 (실측 2026-09-29)

- 도구 `judge` 와 skill 이 있다. `call_service()` 의 요청·응답 형식은 **`미확정`** 이다 — 공개 문서가 필드 이름을 밝히지 않는다. 자격이 오면 그 함수와 고정물 키만 고친다.
- 공개된 비용은 입력 100만 토큰당 **$0.042**, 출력 무료, 케이스당 약 **$0.0004**, 지연 70~500ms 다.
- 이 저장소에서 물을 질문은 문장 단위 근거·중복·자리·채움·요약·라벨 대표성 여섯이다. 청크 800 규모에서 한 회차가 수천 질문이고, 위 단가면 한 회차 비용이 **1달러 미만**으로 추정된다.

## 답이 가르는 것

- **자격을 주면** 3지표 측정이 시작되고 임계가 실측 근거를 얻는다. 판정 로그가 쌓이면 게이트 승격을 판단할 수 있다.
- **주지 않으면** 도구는 고정물로만 돌고 임계 셋은 근거 없는 수치로 남는다. 라벨 대표성 실험처럼 에이전트 세션이 대신하면 캘리브레이션 축은 계속 비어 있다.
- **비용은 판단의 변수가 아니다** — 공개 단가 기준으로 한 회차가 1달러 미만이다. 변수는 자격과 외부 의존을 ODD 에 올리는 것이다.

## 선택지

1. **자격을 주고 첫 측정을 돌린다** (권고). 유저가 엔드포인트·키·모델 식별자를 환경 변수로 주고, developer 가 `call_service()` 를 맞추고 vnv 가 구간별 3지표를 잰다. 비용: 유저 5분 + 요금 1달러 미만 + ODD 조건 하나.
2. **고정물로만 두고 형식만 검증한다.** 비용 없음. 3지표는 비어 있고 임계는 규약으로만 남는다.
3. **에이전트 세션을 판정자로 계속 쓴다.** 확신도를 자기 보고로 받는다. 비용: 없음. 캘리브레이션 축은 판정 불가로 남는다.
