TypeSafe 의 `jev` 를 **System One 모델**로서 상세히 조사해 달라. 2026-09-21 의 생성 문서 규약 반영은 그것을 "출력 형태를 호출 전에
고정한다" 하나로만 읽었다. (유저 지적 2026-09-26)

## 답 (hci, 2026-09-26)

### 1. System One 모델이란 무엇인가

**"소프트웨어가 바로 쓰는 빠른 구조화 결정"을 내는 모델 부류다.** 이름은 카너먼의 System 1(빠르고 직관적인 사고)에서 왔다.
`jev` 가 그 첫 모델이며 2026-09-15 조기 공개됐다. 성질 다섯이 이 저장소에 중요하다.

| 성질 | 내용 |
|---|---|
| 입력·출력 | 구조 없는 **상태**(문자열·JSON·배열)를 받아 **타입 있는 결정 + 확률**을 낸다. 텍스트를 생성하지 않는다 |
| 평가 방식 | **비자기회귀 병렬 표집**. 토큰을 하나씩 잇지 않고 한 질의에서 전부 낸다. 70~500ms |
| 질문의 형 | 셋 — **Noul**(예/아니오, "예"의 확률) · **Choice**(닫힌 집합에서 하나 + 확률) · **Score**(구간 안의 수치 + 확신도) |
| 학습 | **RLCD**(Reinforcement Learning for Calibrated Decisions) — 정답률이 아니라 **정직한 확률**을 목표로 학습한다 |
| 타입 안전 | 가능한 출력과 구조를 **호출 전에** 정하므로 타입 오류가 없다. 파싱 단계가 없다 |

설계 의도는 한 문장으로 이렇다 — **"프런티어 지능의 함수 호출: 구조 없는 상태가 들어가고 타입 있는 확률적 결정이 나온다."**

### 2. 캘리브레이션의 정확한 뜻

문서의 문장이 결정적이다. **"캘리브레이션은 예측 집단에 걸쳐 측정되며 개별 답의 정확성을 보장하지 않는다."**
확신도 0.9는 "이 답이 90% 맞다"가 아니라 **"0.9 구간의 답 무리가 90% 정확하다"**는 뜻이다.
창업자의 근거도 같은 자리다 — "95% 할 수 있으면서 나머지 5%가 언제인지 말하지 못하면 그 작업은 자동화할 수 없다."

### 3. 한계 — 문서가 명시한 것

- **텍스트를 만들지 못한다.** 답장·코드·요약·**설명**을 쓰지 못하고 근거를 자연어로 대지 못한다.
- **열린 답 공간을 다루지 못한다.** Choice 의 **cardinality 상한은 255**이며, 그보다 크면 "독립 점수 → 명시 선택"의 2단계를 쓰라고 권한다.
- 텍스트만 받는다. 이미지·오디오·비디오는 없다.
- 환각 0% 라는 수치는 **경험적 측정이 아니다** — 스키마 일치가 보장되므로 0을 넣었다고 문서가 스스로 적는다.
- 워크플로 벤치마크는 자기 팀이 만들었고 독립 검증되지 않았다고 밝힌다.

### 4. 비용과 권고 패턴

입력 100만 토큰당 $0.042, 출력 무료, 케이스당 약 $0.0004, 초당 10회 수준의 반응형 사용이 가능하다.
권고 패턴은 **"확신도 임계를 두고 그 위만 자동 적용하고, 불확실한 것은 사람이나 느린 LLM 으로 보낸다"** 다.

### 5. 이 저장소와의 대조

결정 `p8-judge-question-form`(2026-09-22)이 이미 같은 형을 채택했다. **질문의 형 셋·원자성·병렬·확신도 임계 셋·척도를
상황으로 적기·계산과 다단계 추론 배제**가 전부 일치한다. 그 결정은 축이 맞다.

일치하지 않거나 비어 있는 것은 여섯이다.

| # | 대조 | 이 저장소 |
|---|---|---|
| J1 | 캘리브레이션이 **집단 수준** | 결정은 임계 셋으로 처리를 가르되 그 뜻을 적지 않았다. 임계를 쓰려면 **구간별 정확도**를 재야 한다 |
| J2 | 도입 표본 | 결정은 "20건 이상 라벨링"이다. 구간이 셋이면 20건으로는 구간별 캘리브레이션을 재지 못한다 |
| J3 | Choice 상한 **255** | 결정에 상한이 없다. "같은 주장을 담은 블록은?"을 청크 776 후보로 물으면 상한을 넘는다. 규약은 "라벨 유사 상위 k개"라 실질적으로는 맞다 |
| J4 | **설명을 만들지 못한다** | 판정 결과를 논평(`annotation`)에 남기는데 논평 틀에는 `본문:` 문장 ≤4 슬롯이 있다. **그 본문을 누가 쓰는가**가 비어 있다 |
| J5 | 모델 버전과 캘리브레이션의 결합 | 결정이 "판정자 모델 식별자와 버전을 맞춘다"고 이미 적었다. RLCD 가 그 규칙의 근거를 준다 — 모델이 바뀌면 확률의 뜻이 바뀐다 |
| J6 | 외부 서비스 호출 | 판정자 실물이 없다. 붙이면 **네트워크·API 키·재현성**이 게이트에 들어온다. 같은 날 열린 `orchestrator-test-hermeticity-2026-09-23` 이 그 자리를 이미 묻고 있다 |

라벨 대표성 실험(2026-09-11)의 판정자는 **새 에이전트 세션**이었다. 그것은 System 2다 — 자유 서술을 하고 느리고 확률을 내지
않는다. 즉 저장소는 판정자의 **형**을 System One 으로 정해 두고 실행은 System 2로 했다.

판단이 필요한 것은 유저 lane 항목 [`../jev-judge-binding-2026-09-26.md`](../jev-judge-binding-2026-09-26.md)로 올렸다.
