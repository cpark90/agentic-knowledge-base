프로젝트 전체 개관을 확인했는데 상위 기획은 어느정도 일치하는데 세부적인 내용들에 기획과 다른점들이 있고, 전체 내용이
하나의 서비스로 통일되지 않고 산발적인면이 있어. 전체 프로젝트를 통일성 있게 다듬고 최적화하려고 하는데 이와 관련해서
기획해줘. (2026-10-01)

## 답 (hci, 2026-10-01)

"산발적"이 어디에 있는지 실측했다. 결론은 셋이다.

1. **기획 → 구현의 인용은 거의 완전하나 충실도는 잰 적이 없다.** 노트 절 157 중 156을 청크가 인용한다. 그러나 인용은 "그 절을 근거로 삼았다"일 뿐 세부가 같다는 뜻이 아니다. 기획과 다른 세부를 찾는 감사가 아직 없다.
2. **도구 층이 각자 자랐다.** 도구 37개·12,447줄. 그래프를 자기 손으로 여는 도구 11, 공통 로더를 쓰는 도구 6. FAIL 접두 종류 44. 진입점은 `bazel run //tools:<이름>` 37개이고 하나의 CLI 가 없다. skill 20 대 도구 37.
3. **첫 형태가 쌓여 있다.** 로드맵에 "첫 형태" 19곳·"부분" 5곳. 완결된 단계는 1·4뿐이다.

기획안은 유저 lane 항목 [`../unification-program-2026-10-01.md`](../unification-program-2026-10-01.md)에 다섯 절과 단계 여섯으로 세웠다.
