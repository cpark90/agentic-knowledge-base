# 판정자의 정확도 축 — 유저 재판정이 필요하다 (2026-10-01 중계)

원본: [`agents/orchestrator-observation-means-2026-10-01.md`](agents/orchestrator-observation-means-2026-10-01.md) ②

## 질문

세션 판정자 둘의 첫 실험이 끝났다. 3지표 가운데 **판별력**(미끼 검출)과 **판정자 간 일치**는 재졌고 **정확도**는 비어 있다 —
정확도는 사람 기준과의 일치이고 그 사람이 유저다. 재판정을 할 것인가, 몇 건을 할 것인가.

어려운 이유는 둘이다. 정확도 없이 일치율 임계를 정하면 "둘이 같이 틀린" 경우를 걸러내지 못한다. 그리고 판정자의 응답 파일이
**다른 세션의 스크래치패드**(`/tmp/…/label-exp/a.json`·`b.json`)에 있어 휘발성이다 — 판정지를 채널로 옮기는 것이 먼저다.

## 이미 정해진 것

- 결정 `p8-judge-question-form` — 자동 적용은 정확도·판별력 둘이 재진 뒤에만 켠다. 확신도는 자기 보고라 캘리브레이션은 판정 불가로 적는다(유저 결정 2026-09-30).
- 노트 8.14 — 학습된 판정자는 3지표 + **사람 승인**을 통과해야 한다.
- 2026-09-11 라벨 실험의 선례 — 유저가 60 중 10건을 재판정해 정확도 축을 채웠고("개별 이의 없음"), 그것이 1단계 "의미 보존"을 닫았다.

## 현재 상태 (실측 2026-09-30, `kb/vv/verdict/session-judge-agreement-first-sample.md`)

| 지표 | 값 |
|---|---|
| 표본 | seed 20260930 · 층화 60(요구 10·결론 20·근거 15·대안 15) + 미끼 10 |
| 판정자 | `judge-a/claude-sonnet-5` · `judge-b/claude-sonnet-5` — 서로 모르는 세션 |
| 값 일치 | **67/70 = 95.7%** (실표본 58/60 · 미끼 9/10). 불일치 셋 — 결론 #12 · 대안 #62 · 미끼 #58 |
| 판별력 | 미끼에 "적합"을 준 판정자 0 — 10/10 |
| 정확도 | **미측정** — 사람 재판정이 없다 |
| 캘리브레이션 | 판정 불가(자기 보고) |

일치율 임계의 표본이 둘(69/70 · 67/70)이라 수치는 아직 정해지지 않았다.

## 답이 가르는 것

- **재판정하면** 정확도 축이 채워지고 일치율 임계에 사람 기준이 붙는다. 자동 적용(0.9 이상)을 켤 조건 둘 중 하나가 완성된다. 비용은 유저 시간 — 10건이면 약 10분이다.
- **하지 않으면** 정확도는 미측정으로 남고 판정은 전부 사람 확인 큐에 머문다. 판정자는 돌되 아무것도 자동으로 적용되지 않는다.
- **셋째 세션으로 대리하면** 그것은 정확도가 아니라 일치율이다. 축이 다르므로 정확도를 채우지 못한다.

## 선택지

1. **10건 재판정** (권고). hci 가 판정자 응답에서 **불일치 셋 + 무작위 7**을 뽑아 채널에 판정지(라벨만 먼저 → 본문 → 3점)로 만든다. 유저가 채우면 vnv 가 정확도를 계산해 관측으로 남긴다. 비용: 유저 약 10분.
2. **20건 재판정.** 구간당 표본 하한(20)과 같은 수다. 비용: 약 20분. 정확도의 신뢰 구간이 좁아진다.
3. **재판정 없이 간다.** 정확도는 미측정으로 두고 자동 적용은 켜지 않는다. 비용 없음.
