# 외부 서비스 없이 판정을 세운다 (2026-09-30)

앞선 항목: [`jev-credentials-2026-09-29.md`](jev-credentials-2026-09-29.md)(철회) · [`handoff/jev-credentials-2026-09-29.md`](handoff/jev-credentials-2026-09-29.md)(철회 기록)

## 질문

유저 지시(2026-09-30) — **`jev` 를 직접 쓰지 않는다. 별도의 서비스를 쓰지 않는 방안을 다시 마련한다.** `jev` 의 방법론과
System One 은 지식 구조화의 **참고**였다. 그러면 판정을 무엇이 수행하는가.

어려운 이유는 셋이다. 첫째, **이미 서 버린 것이 있다** — 도구·게이트·결정·ODD 조건·가정이 외부 서비스를 전제로 만들어졌고
그중 무엇을 남기고 무엇을 되돌릴지 갈라야 한다. 둘째, 확신도를 내는 주체가 없어지면 **임계 셋이 작동하지 않는다.** 셋째,
판정이 필요한 질문 여섯 가운데 기계로 환원되는 것과 남는 것이 다르다.

## 이미 정해진 것

- 결정 `p8-judge-question-form` — 질문의 형 셋(예/아니오·선택·척도) · 원자성 · 출력은 값과 확신도 · 임계 셋 · 도입 전 라벨링 · 계산은 맡기지 않는다. **이 형식 자체가 System One 참고의 산물이고 유지된다.**
- 노트 2.5 — 에이전트는 신뢰할 수 없는 센서다. 판정은 사람 또는 검사 통과 판정자다.
- 노트 8.14 — 학습된 판정자는 정확도·판별력·캘리브레이션 3지표 + 사람 승인을 통과해야 한다.
- 게이트는 밀폐다. 외부 호출이 `bazel test` 의 입력이 되면 같은 리비전이 네트워크 상태에 따라 다른 판정을 낸다.
- 유저 지시 2026-09-30 — 별도 서비스를 쓰지 않는다.

## 현재 상태 (실측 2026-09-30)

**남는 것 — 서비스와 무관하다.**

| 산물 | 내용 |
|---|---|
| 질문·척도·임계 어휘 | 온톨로지 4파일 + shape 1(`judge-question`·`judge-question-set`·`judge-threshold`·`judge-calibration`) |
| 도구의 뼈대 | `tools/judge.py` 383줄 중 질문 읽기·형 검사·**선택 집합 255 상한**·임계 라우팅·판정 로그·결과 주석 |
| 게이트 `judge-log` | 판정 로그의 형식·필수 필드(질문 id·값·확신도·모델 식별자·입력 지문·시각)를 본다 |
| `--fixture` 오프라인 경로 | 기록된 응답으로 같은 경로를 돈다 |

**되돌릴 것 — 서비스를 전제한다.**

| 산물 | 무엇을 뺀다 |
|---|---|
| `judge.py` | `call_service()` 와 `urllib` 호출, 자격 환경 변수 셋(`AKB_JUDGE_*`), 자격 없음 `EXIT_CONFIG` 갈래 |
| ODD | 조건 `id:cond-judge-service`(판정 서비스 도달) |
| 그래프 | 가정 `id:asm-judge-service` 와 그것을 `assumes` 하는 로그·주석의 링크 |
| 결정 | `p8-judge-calibration-binding` 의 외부 서비스 서술 |
| 문서 | `docs/tools.md` 의 `judge` 행과 게이트 총람의 관련 문구 |

**판정 질문 여섯의 기계 환원 가능성**(hci 실측 검토)

| 질문 | 기계로 되는가 |
|---|---|
| 채움 — 슬롯이 질문에 실질적으로 답하는가 | **이미 게이트다**(`addition`·`empty-value` 패턴) |
| 요약 — `핵심:` 항목을 지지하는 블록이 있는가 | **된다** — 참조 존재 검사다 |
| 중복 — 두 블록이 같은 주장을 담는가 | **부분** — `consistency` ③(Jaccard)과 링크가 후보를 좁힌다. 확정은 판단이다 |
| 자리 — 이 문장은 어느 슬롯의 질문에 답하는가 | **부분** — 슬롯 표지·패턴으로 후보를 좁힌다 |
| 근거 — 이 문장은 입력 상태에서 지지되는가 | **안 된다** — 의미 판정이다 |
| 라벨 대표성 — 라벨만 보고 본문을 고를 수 있는가 | **안 된다** — 의미 판정이다 |

즉 **환원 불가는 둘**이고 그 둘이 판정자를 필요로 하는 전부다.

## 답이 가르는 것

- **에이전트 세션을 판정자로 두면** 이 하네스 안에서 돌고 외부 의존이 없다. 대신 **확신도가 자기 보고**다 — 캘리브레이션이 아니라 일치율·미끼 검출로 신뢰를 잰다. 2026-09-11 라벨 실험이 정확히 그 형태였고 캘리브레이션 축에서 "판정 불가"로 끝났다.
- **임계 셋의 뜻이 바뀐다.** 확신도가 자기 보고이면 0.9 이상 자동 적용은 근거가 없다. 임계를 일치율(판정자 둘 이상이 같은 답)로 바꾸거나, 자동 적용을 없애고 전부 사람 확인 큐로 두어야 한다.
- **기계 환원을 먼저 하면** 판정이 필요한 질문이 여섯에서 둘로 줄어 사람·에이전트의 부담이 크게 준다. 지금 미환원 상태로 판정자를 붙이면 넷을 불필요하게 판정한다.
- **되돌리지 않으면** ODD 조건과 가정이 존재하지 않는 서비스를 가리킨다. `assume_check` 가 그 가정을 판정하려 하고 조건은 영구 미충족이다 — 지표와 감사가 오염된다.

## 선택지

1. **기계 환원을 먼저 하고 남는 둘만 에이전트 세션이 판정한다** (권고). ① 되돌릴 것 다섯을 뺀다 ② 요약·채움을 게이트로 확정하고 중복·자리를 후보 생성까지 기계화한다 ③ 남는 둘(근거·라벨 대표성)은 **세션 판정자**가 값과 자기 보고 확신도로 답하고 `--fixture` 자리에 세션 응답을 넣는다 ④ 임계는 **일치율**로 바꾼다(판정자 둘의 일치 + 미끼 검출) ⑤ 자동 적용은 3지표 가운데 둘(정확도·판별력)이 재진 뒤에만 켠다. 비용: 도구 정리 + 결정 개정 1 + 게이트 둘 + 세션 판정 절차 한 절.
2. **판정을 전부 사람에게 둔다.** 판정자 개념을 접고 남는 둘을 리뷰 규범으로 돌린다. 비용: 도구·어휘 제거가 커지고, `verification-means-trust`(검증 수단의 신뢰도를 잰다)가 측정 대상을 잃는다.
3. **로컬 모델로 확률을 얻는다.** 토큰 확률에서 예/아니오 확률을 뽑으면 캘리브레이션이 성립한다. 비용: 추론 스택이 ODD 에 들어오고(의존·하드웨어) 밀폐성·재현성을 다시 설계한다. **외부 서비스는 아니나 새 무거운 의존이다.**
4. **형식만 남기고 판정은 미룬다.** 되돌릴 것 다섯만 빼고 어휘·게이트는 유지한 채 판정 주체는 나중에 정한다. 비용: 정리만. 3지표는 비어 있다.

## 함께 답할 것

**`jev` 참고의 자리를 어디에 남기는가.** 유저 지시대로 방법론·System One 은 참고다. hci 권고는 **결정 `p8-judge-question-form`
의 근거에 출처로 남기는 것**이다 — 질문의 형 셋과 "확신도를 값으로 남긴다"가 그 참고의 산물이고, 서비스 도입은 아니었음을
결정 본문이 적어 두면 다음 세션이 같은 오독을 하지 않는다.
