**질의** — `tools/cq-queries/CQ-02.rq` 다. 10줄이고 이 청크는 추출 생성물이다. 질의 파일 하나가 청크 하나이므로 링크와 가정의 자리가 이 청크다.

<!-- 인용 시작: 소스 파일에서 그대로 옮긴 코드 — 생성기는 원문을 고쳐 쓰지 않는다 -->
```sparql
# 이 항목은 어느 칸에 있는가 (plane × level).
# 행 = plane × level 칸 하나와 그 칸의 살아 있는 청크 수. ?item 을 --bind 로 묶으면 그 항목의 칸
PREFIX agt: <https://agentic-knowledge-base.dev/agt/>
PREFIX id: <https://agentic-knowledge-base.dev/id/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
SELECT ?plane ?level (COUNT(?item) AS ?n) WHERE {
  ?item a ?plane ; agt:hasLevel ?level ; agt:status ?status .
  ?plane rdfs:subClassOf agt:Chunk .
  FILTER(?status != "deprecated")
} GROUP BY ?plane ?level ORDER BY ?plane ?level
```
