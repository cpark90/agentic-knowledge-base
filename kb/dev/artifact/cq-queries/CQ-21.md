**질의** — `tools/cq-queries/CQ-21.rq` 다. 10줄이고 이 청크는 추출 생성물이다. 질의 파일 하나가 청크 하나이므로 링크와 가정의 자리가 이 청크다.

<!-- 인용 시작: 소스 파일에서 그대로 옮긴 코드 — 생성기는 원문을 고쳐 쓰지 않는다 -->
```sparql
# 지금 invalidated·suspect인 항목은 무엇인가.
# 행 = status 가 suspect 또는 invalidated 인 청크 하나 (plane · 상태). 0행이면 상태 전이가 한 번도 없었다
PREFIX agt: <https://agentic-knowledge-base.dev/agt/>
PREFIX id: <https://agentic-knowledge-base.dev/id/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
SELECT ?item ?plane ?status WHERE {
  ?item a ?plane ; agt:status ?status .
  ?plane rdfs:subClassOf agt:Chunk .
  FILTER(?status IN ("suspect", "invalidated"))
} ORDER BY ?status ?plane ?item
```
