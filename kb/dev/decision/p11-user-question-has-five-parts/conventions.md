규약: [지킴] 유저 판단을 요청하는 질문은 **다섯 가지**를 갖춘다(유저 지적 2026-09-02). 다섯 가지는 질문(왜 어려운가 포함) / 이미 정해진 것 / 현재 상태(실측) / 답이 가르는 것 / 선택지다. 한 줄 질문은 답을 받지 못한다. 선택지마다 비용을 적고 `**권장:**`으로 권장안을 붙인다.
