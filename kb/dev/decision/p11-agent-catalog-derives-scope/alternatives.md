**대안** — 카탈로그가 역할의 프롬프트·절차까지 규정하는 안. 기각 — 카탈로그가 규정하는 것은 역할과 권한 요구까지다. 각 역할이 실제로 무엇을 하는가는 하네스의 몫이고 체계 밖이다 (11.2절).
