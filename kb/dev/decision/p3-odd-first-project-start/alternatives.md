**대안** — **빈 ODD로 시작해 작업하며 채우는 안.** 배제 — 채워지지 않은 속성 위에서 만들어진 지식 항목의 전제가 사후에 확정되며, 그때 무효화 범위를 되짚을 수 없다.

**`[안]` 이전 프로젝트의 ODD를 복사해 시작하는 것을 기본 경로로 둔다.** 미확정 — 6.3절 일반화로 자란 온톨로지와 이전 ODD의 조합이 새 프로젝트의 출발점이 된다는 구상이다. 복사본이 검토 없이 남는 위험과 5단계 검증의 관계를 아직 정하지 않았다.
