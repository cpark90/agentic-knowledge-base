**대안** — 유저에게 적은 선택지를 제시하고 고르게 하는 UI. 기각 — 유저는 리포트(`-space`의 변수·후보·제약)를 받고 거기에 피드백을 입력해 결정한다. 그 파일을 읽고 편집 가능하게 노출하는 것이 유일한 UI 요구다 (12.2절, 13.5절).
