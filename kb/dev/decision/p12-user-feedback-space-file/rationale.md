**근거** (노트 12.2절·12.5절)

- 결정할 항목과 배경은 `-space`의 **변수·도메인·제약**, 선택지는 **도메인**,
  결정의 기록은 **concrete 배정 + `refines` 링크**, 완결 판정은 **후보 링크가
  하나 남음**이다. 리포트를 따로 만들지 않는 이유가 이 대응이다.
- 유저가 온톨로지 문법을 몰라도 되게 체크박스 세 상태로 낮춘다 — `[x]` 선택,
  `[ ]` 남은 후보, `[-]` 배제. 체계가 이 파일을 후보 링크 상태로 되읽으므로
  편집이 곧 배정이고 별도 입력 화면이 없다.
- 후보가 하나로 좁혀지기 전의 편집은 피드백 디렉토리 안에 머문다. 반쯤 좁힌
  상태가 채널을 통과하면 근거 없는 배정과 구분되지 않는다.
