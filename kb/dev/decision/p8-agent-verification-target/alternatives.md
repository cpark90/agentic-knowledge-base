**대안** — 넷을 기각한다.

| 대안 | 기각 이유 |
|---|---|
| `verifies`의 대상에 카탈로그 개체를 허용한다 | 분석 시점 검사가 A-Box 개체를 알아야 하고 수준 일치 검사에 예외가 생긴다. 검사 약화이므로 유저 승인 사항인데, 얻는 것은 도착점의 종류 하나뿐이다 |
| 옛 결정을 그대로 두고 에이전트 사슬을 포기한다 | `r-025`가 영구히 사람 확인으로 남고 케이스까지 이어진 목표 비율의 상한이 100% 아래로 고정된다 |
| 에이전트 검증만 별도 링크 타입을 만든다 | 어휘가 늘고 TIM 칸이 늘며 `verifies`의 뜻이 갈린다. 같은 관계를 두 이름으로 부르는 것이 이 체계가 막는 드리프트다 |
| 하네스·스코프를 청크로 승격한다 | 카탈로그는 A-Box이고 `kg/`의 손으로 쓰는 개체다. 청크로 올리면 역할·스코프의 정의처가 둘이 된다 |
