# 설계 공간의 확정·배제는 직접 답할 때만 (유저 채택 Q65-b, 2026-10-06)

- 유저는 미결을 "개선 및 확장이 이루어지는 frontier 포인트"로 본다(Q54-a). 미결은 설계 공간(`space/*-space.md`)에 산다.
- 대행·orchestrator가 기존 결정을 "해석"해 후보를 confirmed·eliminated로 두면 frontier가 줄어든다. 유저는 그런 해석 판정을 되돌리는 쪽(Q65-b)을 골랐다.
- **How to apply:** orchestrator의 status·result에 "대행이 내린 판정"·"근거 배정"이 있으면 근거 결정의 원문을 직접 읽어 대조한다. 문장이 직접 답하지 않으면 질문지에 hci의 읽기로 세우고 열린 후보로 되돌리는 안을 권장한다.
- 같은 종류: 기존 청크를 후보로 재사용한 "동일성 판정"(Q63·Q64)은 유저가 orchestrator 판정을 그대로 인정했다 — 원문이 같은 원칙을 들 때.
