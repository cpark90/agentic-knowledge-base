유저 답 Q170-c(Q-0074, 2026-10-26): 링크 후보 뷰에 새로 든 판정 없는 후보는 묻지 않고 판정해 기록한다. 한 번에 생기는 새 기록이 50개를 넘으면 묻는다. 기록 수와 판정 결과는 매번 result로 알린다.

**Why:** 판정 기록은 정해진 도구가 만드는 기록 파일이고 손으로 쓰는 새 지식이 아니다. 매번 물으면 뷰가 바뀔 때마다 판정 없는 후보가 큐 밖에 남는다(0316·0321의 사례).

**How to apply:** orchestrator가 판정 기록의 새 파일 수를 50개 이하로 보고하면 질문지를 열지 않고 result로 확인만 한다. 50개를 넘거나 판정 기록이 아닌 새 파일이면 Q66대로 질문지로 묻는다. 원본 반영은 task 0322(결정 p11-user-question-has-five-parts)다. [[concurrency-check]]
