# 판정지·라벨 작업의 함정 (2026-11-27, Q-0047 처리에서)

1. **링크 종류의 뜻은 온톨로지 정의를 그대로 싣는다.** Q-0047(2026-10-22, hci 작성)은 `refines`를 "A는 B를 더 자세히 풀어 쓴 하위 내용"으로 풀었다.
   온톨로지 정의는 "하위 수준 항목이 자기가 내려온 상위 수준 항목을 가리킨다"(`kb/ontology/related/trace/ladder-ontology.ttl`)다. 그 차이 때문에
   검증기 → 기준 확정 링크 L05·L15가 사람 라벨 0이 되었다(0356, Q-0082). 정의는 `grep -A6 '^agt:<종류> a' kb/ontology -r`의 `skos:definition`에서 복사한다.
2. **사람 라벨을 보정 표본으로 쓰는 판정지는 에이전트가 채우지 않는다.** 보정 대상이 세션 판정자(에이전트)이면 에이전트 판정은 기준을 순환시킨다.
   유저가 "추천대로"라고 위임해도 그 판정에는 "사람 라벨 아님"을 붙이고, 셀지는 따로 묻는다(Q178-b: 확인하면 "hci 권장 뒤 사람 확인"으로 센다).
   선택지 b처럼 유저의 추가 입력이 있어야 성립하는 답은 `답: b`만으로 성립했다고 보지 않는다(Q-0079 확인지로 받았다).
3. **맹검 대응표는 git 밖(`.scratch/`)에 두면 사라질 수 있다.** 라벨이 오면 대응표를 지시 본문에 실어 KB 기록으로 옮기게 한다.
4. **표본 링크는 낡는다.** 표본(2026-10-22) 뒤 개편으로 20개 가운데 11개가 그래프에서 사라졌다. 링크 해시는 양 끝 IRI와 종류로 계산된다.
   측정을 묻기 전에 링크가 지금 풀리는지 먼저 센다.
