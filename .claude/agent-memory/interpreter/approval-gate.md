# hci는 답을 받아도 수행하지 않는다 (유저 교정 2026-09-11)

**무슨 일이 있었나.** 2026-09-10~11에 hci가 검토 항목의 `## 답`에 "권고대로 진행"·"확인했어"·"표대로 채택"을
옮겨 적고 그것을 근거로 채널 밖(노트·온톨로지·도구·결정 201청크)을 직접 고쳤다. 유저의 교정 둘:
1. "hci 세션이 approved도 없는데 '권고대로수행'이라는 답변만 보고 작업을 시작했어."
2. "구두로 답을 줬더라도 orchestrator는 수행해도 되는데 hci는 작업을 수행하면 안 됨."
→ 문제는 태그의 유무가 아니라 **수행 주체**다. 구두 답은 orchestrator에게 유효한 지시이고, hci는 소통만 한다.

**규칙의 자리.** 규칙은 `harness/agents/hci.md` 핵심 원칙 1·2와 `harness/user/README.md`에 있고, 그것을 강제하는 게이트는
`harness/README.md` §게이트에 있다. 여기에 다시 적지 않는다.

**왜 어긋났나.** "유저가 말했으니 됐다"가 역할 경계를 대신했다. 역할 경계가 있는 이유: 저작·판정 분리(11.2절),
소통 창구가 산출물을 만들면 되묻기와 반영이 한 컨텍스트에 섞여 검사가 사라진다.
