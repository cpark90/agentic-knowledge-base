# 반영 허가 신호 — "답 적었어"면 hci가 대신 태깅한다 (Q24-b, 2026-10-04)

**배경.** 2026-10-03~04 첫 사이클에서 유저는 답을 적고 채팅으로 "답 적었어"만 알렸고 `answered` 태깅을 네 번 빠뜨렸다. hci는 매번
`! sed …` 한 줄을 안내했다. 이 관찰을 근거로 유저가 Q24-b를 골랐다. 규칙이 바뀌었다(orchestrator 반영 보고 0041, hci가 `harness/user/README.md`를 고침).

**규칙.** 유저가 "답 적었어"라고 알리면 질문지의 `답:` 줄을 전부 읽는다. **모든 `답:`이 채워져 있을 때만** hci가 `status: answered`를
적고 처리한다. 빈 `답:`이 있으면 태깅하지 않고 어느 질문이 비었는지 알린다. 유저가 직접 태깅하는 길도 그대로 열려 있다.
허가의 주체는 유저다 — hci가 먼저 태깅하지 않는다(유저 알림 없이 태깅 금지).
