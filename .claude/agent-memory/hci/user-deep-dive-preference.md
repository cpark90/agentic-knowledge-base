# 유저는 깊은 조사도 hci가 직접 하길 원한다

2026-09-02: "3.은 네가 상세하게 조사해봐야할것같아" — 조사 lane(inspection 위임)
대신 hci가 저장소를 직접 읽고 답하기를 원했다. 조회 범위가 저장소 전체이므로
가능하다. 결과는 대화에 전체 내용을 보이고(터미널에는 tool 출력이 안 보인다 —
표·수치는 답변 본문에 넣는다), 상세와 결정 요청은 유저 lane 항목으로 남긴다.

**반복 질문 패턴**: "왜 X가 없나 / 왜 Y에만 적용됐나" — 답은 대개
`docs/roadmap.md`(현재 위치·다음 산출), `docs/tools.md` "게이트 밖" 표,
`docs/risks-and-tensions.md`(자인한 방어 공백), `docs/open-questions.md`(미해결)에
있다. 결정(d-NNNN)과 실제 파일을 대조하면 불일치가 나온다 — **문서의 수치는 낡기 쉬우니**
`ls | wc -l`·`grep -c`로 실측한다.

**중계 함정**: 세션 밖 질문(Claude Code 사용량 등)도 온다 — 로컬 데이터(세션
파일 시각)로 근거를 대되 내용은 읽지 않는다.
