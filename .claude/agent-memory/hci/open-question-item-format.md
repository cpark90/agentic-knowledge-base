# 미해결·결정 요청 항목의 최소 구조 (유저 피드백에서 나온 교훈)

2026-09-02 유저: "한문장의 짧은 질문으로는 해당 항목에 대한 내용파악이 힘든것같아."
docs/open-questions.md의 한 줄 항목으로는 답을 받을 수 없었다. 유저에게 판단을
요청하는 항목은 반드시 다섯 절: **질문(+왜 어려운가) /
설계가 이미 정한 것(청크 IRI) / 현재 상태(파일·실측 수치) / 답이 가르는 것 /
선택지 2~3개(+비용)**. 그리고 `## 답 (유저가 채움)`.

라벨 한 줄은 인덱스다 — 내용이 아니다. 채널 항목의 targets에는 IRI·경로를 넣고,
본문 수치는 반드시 실측(`ls|wc`, `grep -c`, awk)한다 — 문서의 수치는 낡아 있다.
